# Homebrew tap for MaldocTrace

```sh
brew install debugactiveprocess/tap/maldoctrace
maldoctrace version
```

[MaldocTrace](https://github.com/debugactiveprocess/MaldocTrace) is a static analyzer and safe VBA emulator for malicious Office documents. The formula installs the prebuilt release binary for macOS or Linux (amd64 and arm64) and checks it against the release SHA-256.
